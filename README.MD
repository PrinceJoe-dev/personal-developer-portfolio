
# Personal Developer Portfolio Website

## Project Description
This project is a personal developer portfolio website
created to introduce a Software Engineering student,
showcase technical skills, display projects and provide
contact information.

## Technologies Used
- HTML
- CSS
- JavaScript
- Git
- GitHub

## AI Tool Used
ChatGPT was used as the AI development assistant.

## How AI Helped
ChatGPT helped generate the initial HTML structure,
suggest CSS styling, organize the webpage sections,
write JavaScript functionality and improve the
responsiveness of the website.

## Features
- Home section
- About Me section
- Technical Skills section
- Projects section
- Contact section
- Responsive design
- Interactive JavaScript functionality

## How to Run
1. Clone or download this repository.
2. Open the project folder.
3. Open index.html in a web browser.
